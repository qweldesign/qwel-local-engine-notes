# QWEL Local Engine Project Notes

This repository contains extracted notes from QLEP —  
reusable structures distilled from the running log.  
These are composed from experiments and records in the [devlog](https://github.com/qweldesign/qwel-local-engine-devlog).

このリポジトリには、QLEPのログから抽出されたノートを収めています。  
エンジンを回す過程で見えてきた、再利用可能な構造を整理したものです。  
これらは、[devlog](https://github.com/qweldesign/qwel-local-engine-devlog) に記録された実験や試行をソースとして構成されています。

> **About QLEP**  
> QLEP stands for QWEL Local Engine Project —  
> a small playground for Scratch, p5.js, Three.js & Blender with my kids.
> 
> **QLEPについて**  
> QLEP（QWEL Local Engine Project）は、家庭というローカルな場で、  
> Scratch / p5.js / Three.js / Blender を行き来しながら、  
> 思考と表現のエンジンを回し続けるための思想的機構です。
